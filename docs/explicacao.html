Como funciona

O site pergunta, a API responde, o banco guarda

Navegador

index.html · api.jsA página abre com o conteúdo fixo. O api.js pergunta se a API existe e, se existir, troca cartões, fórum e FAQ pelo que vem do banco.
→JSON
/api/*

Servidor

backend/server.mjsEntrega os arquivos do site e atende as 18 rotas. Valida cada campo, confere o login e nunca expõe a pasta do banco.
→SQL

Banco

backend/schema.sqlSQLite, um arquivo só. Chaves estrangeiras, CHECK e UNIQUE recusam dado errado mesmo fora da API.

Se não houver servidor, nada quebra

Aberto no GitHub Pages ou direto do disco, o api.js não encontra a API e não faz nada. A página fica idêntica à de hoje. Isso deixa o grupo publicar o front agora e ligar o banco quando a hospedagem for decidida.

Exemplos

O mesmo site, agora com dados de verdade

O navegador envia

POST /api/cadastro

{
  "nome": "Bia",
  "login": "bia9a",
  "senha": "segredo-123",
  "codigo_turma": "DEMO-9A"
}

O banco grava

-- tabela usuarios
id            5
nome_exibicao Bia
login         bia9a
senha_hash    fb9f98ad…:… (scrypt)
papel         aluno
turma_id      1

A senha não aparece em lugar nenhum do banco, só o hash. O papel é sempre aluno: se alguém enviar "papel": "admin" pelo navegador, a API ignora. Há um teste automático para isso.

A consulta que vira evidência para a extensão

SELECT * FROM vw_indicadores_escola;

escola                     status_parceria  turmas  alunos_cadastrados  aulas_concluidas  circuitos_salvos
Escola Exemplo (fictícia)  prospeccao       1       4                   2                 0

Resultado real do banco depois da demonstração das capturas acima. Quando houver escola confirmada, a mesma consulta mostra o alcance da ação.

Como rodar

  1. Abra a pasta TEAM_BOTS\Team-Bots-bancoEm C:\Users\dudup\OneDrive\Documentos\PROJETOS\Uniube. É uma cópia do repositório do grupo com as partes novas.
  2. Dê dois cliques em INICIAR.cmdOu, no terminal: node backend/server.mjs. Precisa do Node 22.13 ou mais novo. Não tem npm install.
  3. Acesse http://localhost:3000Na primeira vez o banco é criado em backend/data/teambots.sqlite com os dados iniciais.
  4. Rode os testesnode --test backend/tests/api.test.mjs — 17 testes, cada um em um banco em memória.

Vale avisar o Isaque, porque os dois afetam a main independentemente do banco.

Além disso, o index.html ganhou três linhas: o banco.css, uma seção vazia #cursos e o api.js. O style.css não foi tocado.
